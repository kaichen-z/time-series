Dictionary → Champion → 三 Agent Co-evolution

先通过一次 evolve 构造可执行、可筛选的 Dictionary；再通过第二次 evolve 学习如何选择和组合其中的方法；最后才让 Numerical、Retrieval、Decision 按坐标共同进化。

Train / Dev 职责已统一 80 Train cross-fit · 20 Dev 唯一验收门 · Public-99 sealed

完整生命周期有两次 Numerical evolve

Dictionary 先产生候选供应，Champion 再学习选择方式

Stage 1 · Dictionary Evolution

构造“能用哪些方法”

从原始 Catalog 出发，完善 methods.py / policies.py，再学习每个方法的状态和 applicability，冻结 reviewed dictionary.py。

Stage 2 · Package-native Champion Evolution

学习“怎样选和组合”

对每条序列生成 Active Dictionary，在 package-native Numerical coordinate 中提出 select / route / weighted / overlay recipes；assumption 属于具体 recipe Child。

Stage 3 · Three-Agent Co-Evolve

让证据改变下一轮结构

Retrieval 检验 assumptions，Decision 在已执行候选中选择，Host 把 Train-only 归因反馈给下一代 Numerical。

当前代码事实：run_package_coevolution.py 不是全流程入口。它只消费干净、冻结且 fingerprint 匹配的 methods.py + policies.py + dictionary.py，并且还要求一个冻结的 numerical_champion_release。Method evolution、Filter/Screening 和 Champion evolution 已有独立组件与命令，但当前没有一个命令把它们自动串到 package co-evolution 前面。
设计规格 · 待代码实现：新增薄编排层 scripts/run_full_coevolution.sh，顺序调用已有阶段并验证交接清单；Package runner 保持独立、只读上游产物和向后兼容。本页下面描述的是要实现的契约，不代表脚本或新版实验结果已经存在。

You are evolving a Python module of forecasting methods against measured
results on a training set. You see the entire module and each method's measured behavior, and
you restructure the module so it becomes a smaller set of genuinely distinct, working methods.

Every method is a module-level function named exactly after the method. It receives history as a
list of floats, horizon as an int, and frequency as a string, and returns exactly horizon finite
floats. There are no fallbacks. If requirements are not met, raise NotApplicable before running
the algorithm. Crash and invalid output are defects; honest NotApplicable is not a failure.

Judge on Train evidence. Treat capped mean_smae and mean_srmse as a Pareto pair. Repair defects,
merge genuinely redundant methods, keep a narrow method when it is strong on a coherent series
type, delete only with dominance evidence, and add only for a series type where current methods
score badly.

Return exactly one JSON object with ordered delete, rewrite, merge, or add operations. Every
operation must cite the supplied measurement that justifies it.
