Time-Series 三 Agent Co-evolution

Numerical 负责提出可执行预测，Retrieval 负责寻找和验证上下文证据，Decision 只能在已执行候选中选择。Evolution 逐个冻结坐标，只有通过隔离 gate 的 Child 才替换 Parent。

Train / Dev 职责已统一 80 Train cross-fit · 20 Dev 唯一验收门 · Public-99 sealed

数据如何被使用

当前正式协议；黄色仅标注新版 smoke 的缩小规模

80Train：学习与选择产生候选、hindcast、任务反馈；内部按 8 → 32 → 80 successive halving
smoke：8 Train，不再切 Calibration
5×Train cross-fit按 entity 分组做 5-fold OOF；每题都轮流作为 held-out Train
20Dev：唯一验收门冻结 Child 后只做 accept / reject
smoke：N 个 Dev
99Public冻结后一次性测试，不反馈

详细 task feedback 只来自 Train。Dev 不参与 proposal、参数调整或任务级反馈；Public-99 不进入 selection、rerun 或 feedback。

交给 Retrieval： forecast 保留在 host；只有清洗后的四字段 assumption 可以进入 Retrieval Round 2。

Two-stage Retrieval 的内部顺序

host 在每个边界做 schema 与引用验证

Round 1只看 target、documents、retrieval skills；不知道 Numerical 候选。
→
Host verify逐字引用、实体、目标、时间、机制、预算。
→
Provisional Decision发现证据缺口，产生 typed gaps。
→
Round 2 + Final只接收四字段 safe assumptions；合并后再次 Decision。
Fail closed：Round 1 无效 → 纯 Numerical/Toto；Round 2 无效 → 保留已验证 Round 1；Decision 无有效 override → Toto。

Coordinate evolution：一次只改一个 Agent

Parent 始终是最后一个被 gate 接受的完整 bundle

每个有效 Child 都要过的 gate

前一层失败后，后层不应成为发布依据

1 · Structural

schema、坐标 ownership、forecast 长度、有限值、release lineage、不可变 runtime 身份。

2 · Train cross-fit

8 → 32 → 80 筛选；完整 Train-80 上检查 OOF joint gain、task regret、fold 稳定性、tail 与 catastrophe 安全。

3 · Dev acceptance

冻结后的唯一独立验收门。只返回通过或拒绝所需的聚合证据，不把 task-level Dev 结果送回 Agent；Public 保持 sealed。

Interaction smoke 中 Retrieval 允许按完整性而非 forecast gain 接受，目的是验证三 Agent 通路；这不等于正式 finalist。

失败如何反馈到下一轮

反馈是 typed evidence，不是让 Agent 互相任意改代码

Observed outcome候选覆盖、证据质量、最终选择与 fallback 都进入 task ledger。
→
Failure attribution区分 Numerical coverage、Retrieval chain、Decision regret；去掉未来值和危险字段。
→
Next Numerical proposal下一周期只看到 sanitized cases，据此保留或改变 assumption/operator。

run_manifest锁定 split、runtime、模型、seed、Train-80 / Dev-20 schedule、5-fold manifest 与源码 fingerprint；resume 时必须一致。
coordinate_trace每个 generation 的 Parent、Child、accepted bundle、changed module、拒绝原因与 Public access 状态。
stage_evidence保存 screen8 / screen32 / train80 / dev20 的 parent-child 指标与 gate failures；任务级反馈只从 Train 生成。
final_bundle + completion只包含已接受坐标；完成标记封闭 run lineage，之后才允许独立的一次性 Public evaluator。
