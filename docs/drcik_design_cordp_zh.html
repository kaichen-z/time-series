可审计的自进化跨模态预测
从"证据抽取"到"文档锚定纠正 (CorDP)"

在数值基础模型 Toto 之上，用文档证据、通过可进化 / 可审计的调整层修改预测。核心创新："文档如何改数值预测"这条跨模态交互策略，由进化发现为可读代码，而不是人手设计。

Dr-CiK 80 / 20 / 99 base = Toto-2.0-22m（强） 感知 = haiku（缓存） 策略 = 进化的纯代码

0一句话

纯数值已封顶（champion ≈ Toto），"选候选"范式也封顶。文档里有真信号（oracle 诊断：12/20 dev 题最优缩放可降误差 ~33%），但旧的"让 retrieval 吐 {方向, 量级}"范式里，量级恒为 unknown。本设计的转折：不再抽取抽象量级，而是把 Toto 基线数值 + 文档一起给 LLM，让它输出锚定在具体数值上的"纠正乘子"（CorDP）——量级墙由此打破。

五条亮点

⓪ 稀疏数据上:"判断自己是否过拟合"比"进化出更强策略"更重要

今天整条诚实链(held-out → k 折 CV → 跨域(leave-domain-out)CV → 显著性门 → meta-验证)反复证明:任何"进化出的复杂策略"一诚实评估就露馅(whole-99 −1.2%/28 回归)。真正的能力不是策略更强,而是系统能自己分清"这个提升是真的、还是噪声里的过拟合"。正是这套"自我判断过拟合"的能力,让它在稀疏数据里不自欺、自动收敛到 do-no-harm,并把真实的残余价值(文字侧召回杠杆,+2.50% 零回归)精确定位出来。在小数据上,可信的评估器 > 更强的优化器。

① 文字→数学的原则

文字给出数学操作的结构和一个指向数值来源的指针，绝不发明数值。数值只来自"明确引用 / 数据类比"，两者都没有 → 弃权。落地为逐参数 grounding 标签。

② 锚定破量级墙

把"抽象问量级(→unknown)"换成"给 LLM 看基线数值让它纠正"，量级变可用。task_163 乘子 0.93 vs oracle 0.935。

③ 可审计的进化符号策略

交互策略是可读代码(原语+参数)、由进化发现、内核保证有界+grounded——非黑箱 LLM、非训练模型。读得懂 / 追得到 / 证得了安全。

④ 稀疏对抗数据上精度优先

grounding+弃权 → 稀疏低利用率对抗数据上零回归净正，正是"改所有"(净负)与"数据饥渴"(过拟合)失败的 regime。

定位对比： NEXUS(2605.14389)让 LLM 直接出数打赢 TSFM，但只比 TimesFM+CoT(没放统计方法)、仅赢 ~7%；LAFP(2607.24892)诚实地比强/弱基线——强基线 CiK 仅 2-6%、弱基线 60%。规律：文字大胜多来自弱基线 / 漏比统计 / 为文字设计的基准。我们不赌"LLM 替代强 TSFM"，而是"强 TSFM 之上稀疏安全加分"——在别人回避的强基线+对抗稀疏 regime 上做到零回归。

创新点(诚实版:真正新的 vs 借来的)

一句话:首个"可审计、自进化、带 do-no-harm 可证保证"的跨模态(文字→数值)预测修正 harness,并给出"文档证据何时应当修改一个强预测"的统计刻画(密度×精度交叉),在稀疏对抗 regime 上验证。

真正新的对谁新
① "何时修正才有益"的统计理论(密度×精度交叉 + confounder 不可分下界)对所有人——NEXUS/LAFP/Last Mile 全纯实证,没人给"何时有益"的条件/下界
② 可证 do-no-harm 的 harness(内核+弃权→有界后悔)Last Mile(有约束无保证)、Meta/Self/Harness-R1(优化 harness 无安全证明)
③ 自进化的跨模态交互策略(可读代码)Last Mile(手写 prompt)、NEXUS(黑箱)
④ 稀疏对抗 regime 当贡献(三方 ablation)整个领域(都在稠密基准刷 SOTA)
⑤ gt 监督进化 retrieval 选择Last Mile(不碰 retrieval)

诚实:哪些不是我们的创新(借来的)——CorDP 锚定修正=Beyond-Naive-Prompting;动作式可审计 harness≈Last Mile;进化 harness=Meta/Self/Harness-R1(他们做 coding agent);RAG 式选择=老思路。单看任一组件都是增量;创新在"组合成一个有保证的对象 + 理论"。 → 投 AISTATS 主打 ①理论 + ④稀疏 regime,系统(②③⑤)当理论的可审计实例;若把重心放"造了个系统"则创新弱(都借来的),放"何时/能多大程度用文字改强预测的理论 + 可证安全 harness"则创新硬。

1关键转折：为什么是 CorDP

旧范式（抽取）为何封顶

retrieval 读文档 → 结构化 {direction, magnitude}。给数据上下文后 LLM 变保守，magnitude 返回 unknown；纯数据也估不出事件幅度（短历史无该事件先例）。regime-fill、analog scaler、自一致性多采样等变体全部 LOO 退化。

= 文献点名的失败模式："推理对、数值应用错"。

新范式（CorDP 纠正）

给 LLM 看基线预测数值 + 文档，让它输出每个子窗口的乘子。量级锚定在具体 Toto 数上 → unknown 变为可用的数。

文献支撑：CorDP (2508.09904) 纠正而非抽取，+50%；LAFP (2607.24892) LLM 只排序不吐数字，强基线 CiK 仅 2–6% / 弱基线 Time-MMD 最高 60%。

2系统流程（当前设计）

① 数值层 · 多候选缓存
Toto（最强，当 base）+ statistical + combined + coding-agent 生成代码。champion ≈ high_toto_balanced。
↓
② 感知层 · LLM 只做一次、结果缓存缓存
(a) retrieval 证据：结构化 EvidenceEffect（方向 / 窗口 / 引用）。(b) CorDP 纠正：给基线数值 + 文档 → {relevant, corrections:[{start,end,multiplier,rationale}], confidence}。两者缓存成 per-task 卡片，进化时不再调 LLM。
↓
③ 不变内核 · 永不进化固定
安全 + 测量契约：① 始终有强 base（Toto）兜底；② 最终经 apply_bounded_delta 夹在 base ±50%，非有限值回退 base；③ 调整只作用于有据（grounded）证据；④ 适应度 = 固定的留出集指标。任何进化出的策略都被它兜住，崩不了。
↓
④ 可进化 Controller · 指令有序序列进化
状态机 ControllerState 上的一串可读原语。顺序与选择——即证据怎么改预测——是进化探索的对象。

CorDPAdjust 的精度门（全部可进化）——"文献手设、我们进化"的贡献点

  • conf_min：LLM 自报置信度低于此 → 弃权（不动 Toto）
  • wfrac_max：纠正窗口占 horizon 比例超过此 → 拒绝（全局重缩放是基线的活，一定误动）
  • mult_lo / mult_hi：乘子夹紧（内核再兜一层 ±50%）
  • shrink：部分信任 eff = 1 + shrink·(m−1)

文献里 CorDP / IC-DP / LAFP 的这些阈值全是人手设的；把它们（以及"选哪个原语"的编排）进化成可读代码是新的。

4进化与积累

进化算法 · parent → child（μ+λ）

就是父代→子代的世代进化。种群 = 一堆 controller；每一代：

  1. 按 (适应度, −步数) 排序 —— 简约性平手打破（短的赢，更可审计）
  2. parents = 前 elite 个（μ）；精英直接存活进下一代
  3. 补满到 pop_size：50% 取两个父代 crossover 交叉，50% 复制单父代，然后 mutate（插入 / 删除 / 重排 / 改参数）
  4. pop = children → 下一代，全程追踪 best
parents (elite μ) ──┬─► 精英存活 ─────────┐
               ├─ 50% crossover(p₁,p₂) ─► mutate ─►├─► children = 下一代 pop
               └─ 50% copy(p) ─────────► mutate ─►┘

种子 = SEED_CONTROLLERS（含 CORDP_CONTROLLER）+ 技能记忆积累的历史 champion。适应度 = CVaR 下行（mean + β·最坏尾均）/ 窗口 ROI，重罚回归。

三个环都是 parent→child： B（controller）= 标准 (μ+λ) 带 crossover + 精英；A（retrieval 权重）/ N（数值组合权重）= 更轻的 ES（top-k 父代 → 高斯变异子代，N 还带 CV / held-out + L1 选择）。

技能记忆（积累）

把进化出的好 controller 存成 JSON、去重、下轮当种子（Voyager / AlphaEvolve 程序库思路）。注意：积累的是"原语的组合"，不是新原子原语——原子原语由人 / LLM-design 写。

进化结果（2026-09-19）

  • 前提坑解决：全 horizon+CVaR 目标下进化收敛 identity（窗口收益被稀释）；换成 ROI 窗口指标后，进化找到非平凡 controller（不再"什么都不做"）。
  • 找到的是一条精度/召回 frontier：train ROI 上 conf≥0.9 = 6赢/0回归（保守零回归端）→ conf≥0.6 = 21赢/13回归（激进端）。进化通过下行惩罚 β 在这条 frontier 上滑动——β=2 到零回归端，mean 到激进端。
  • 进化(mean)选的激进门 conf≥0.68 在 test99 上也泛化：+2.5%/+4.6%、28赢/2回归（比手设保守门 17赢/0回归聚合更高，但多 2 回归）。
  • 正规流程已跑（train 搜 → dev 选 → test 定）：门是逐任务的→train 内 LOO≈in-sample，真正关卡是 dev；但 dev 太小（12 ROI / 4 touched）选不动——它选出的松门在 dev/train 上评得差却在 test 上强，说明数据驱动自动选门在 Dr-CiK 上不可靠（再次坐实稀疏/数据受限）。

定理非正式陈述对应实证
T1 · Do-no-harm 可采纳性有界内核(|Δ|≤κ|base|)+ 无据弃权下,相对 base 的最坏退化有界;当证据精度 p 超过阈值时,期望损失 ≤ base(admissible / no-regret)。test99 零回归不是运气,是可证性质
T2 · 密度×精度交叉(核心)任务以密度 ρ 含真信号、精度 p、量级 m。推导 gated vs modify-everything 的期望净增益,证明 ρ→0 或 p<1 时 gated 严格占优,并给出最优门阈值随 (p,m) 的闭式。三方 ablation(改所有净负、我们正)+ 待做的密度扫描图
T3 · Confounder 不可分下界若 confounder 在内容特征上与 supporting 对抗性不可分,则任何基于内容特征的选择器,confounder 拒绝率有上界(<1),存在不可约误差(信息论下界)。纯代码 causal 无用 + LLM verifier 反了(60%>47%)

AISTATS 定位:主定理 = T2(密度交叉 + 最优门,配密度扫描实验);支撑 = T1(harness 的 do-no-harm 保证)+ T3(不可分下界)。系统(CorDP/进化/三环 CCEA)= 理论的可审计实例化。→ 理论 + 系统 + 实验三条腿。

6direct 预测 vs 逐步（残差传播实验）

基线该一次预测整段（direct）还是逐步 AR（step-by-step）？逐步的唯一真正优势是让修正向前传播（停电后的恢复曲线、永久水平移）；代价是误差累积 + 漂移。我们没有真做 AR，而是用 ResidualAdjust 的形状（step=持久、decay=回落）符号化地测"传播"，避开 AR 的漂移。

残差范围（同门 conf≥0.8, wfrac≤1.0）sMAEsRMSEjoint 赢/回归
局限窗口（level，效果只在事件窗口）+0.93%+3.13%14 / 5
带到末端（step，持久传播）−3.27%+1.89%5 / 14

结论：局限窗口完胜传播（14:5 vs 5:14）。 Dr-CiK 的文档事件绝大多数是局部的——效果就该待在事件窗口里，不往后传。所以：基线保持 direct，逐步 AR 帮不上忙（它的传播优势在这里反而有害）；而"拒绝全局/持久修正"的 wfrac 门也由此得到印证。真正需要"传播"的少数事件，用 decay 形状符号化表达即可。

8核心命题：如何用文字做数学

文字→数学 = 三件事的乘积，别混：① 结构（哪个变量/方向/窗口/形状——文字擅长、免费）× ② 数值（真正的难点）× ③ 信任（何时该闭嘴）。

文字负责给出数学操作的*结构*和一个*指向数值来源的指针*，绝不负责*发明数值*。数值只能来自"明确引用"或"数据类比"；两者都没有时，唯一正确的操作是"不动"。

量级墙的本质：当数值既不在文档（明说）也不在数据（类比）里时，无中生有必错——门（confidence + 局部性）就是识别这种情况并弃权。ResidualAdjust 的 grounding 标签把这条原则做进了每个参数。

贡献定位：神经符号 + 分层自进化——LLM 只做不可约的感知（读文档 → 缓存的结构化纠正），进化的纯代码做全部策略，且输出可审计（grounding 覆盖率、有界证书、可读规则）。文献都人手设这条交互策略；没人自进化它、也没人产出可审计的交互规则——这是本工作的空白点。
