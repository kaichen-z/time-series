# Numerical / Retrieval / Decision 三角色自进化在 Dr-CiK 和 Time-MMD 上的实验报告

日期：2026-09-26/27。代码位于 time-series repo 的 `.scratch/self_evolving/`。
所有指标都是相对 Toto-2.0-22m 的改善（正数表示更好）：sMAE、sRMSE，以及联合误差（sMAE+sRMSE，Dr-CiK 点预测指标，上限 5）。"变好/变差"指改善和变差的任务数。

## 0. 实验协议与数据使用记录

| 项目 | 设定 |
|---|---|
| Dr-CiK 切分 | `splits/drcik_public_80_20_99_v3.json`：训练 80 / dev 20 / public_test 99（合成任务）。另有 80 个 human 任务，标签隐藏，从未使用 |
| Time-MMD 切分 | 894 个任务：训练 531（去掉 54 个含非有限值的任务后为 477）/ dev 181 / test 182 |
| 基础模型 | Toto-2.0-22m，使用缓存的预测。我在截断历史上补跑了 Toto 回测，和缓存预测的相对误差约 5e-7 |
| 选择依据 | 所有选择只在训练集上做。主要估计方式是训练集上的嵌套"按领域分层"交叉验证：外层 3 个 fold，每个领域的任务分散到各个 fold，和 train/test 的切分方式一致。最初用过"整组领域留出"的交叉验证，但太严了：连手工方法在那种设定下都是负的，而实际上 95% 的 test 领域在训练集中出现过 |
| dev 把关 | 每个最终方法只开一次 dev；sMAE 和 sRMSE 都不变差才算通过，否则退回 Toto |
| test | Dr-CiK public_test 在 nrd3 时首次打开（9/26 15:50 UTC）。之后所有 test 数字都属于**探索性**，并且应你的要求又打开过多次，所以 **test 数字不能用来在方法之间做选择** |
| 文档标签 | 文档的 `role`/`subtype` 标签从不给任何模型。`annotations.gt_evidence` **只在训练集上**用作 Retrieval 进化的信号（tl2） |

## 1. 进化设计（按时间顺序）

| 版本 | 文件 | Numerical | Retrieval | Decision | 联合进化 |
|---|---|---|---|---|---|
| nrd v1/v2 | `nrd_coevolve.py` | 从 31 个已缓存方法里选最多 5 个，外加聚合方式 | 按词表和阈值过滤 | 向所选候选混合的权重 + 逻辑回归式的证据接受 | 联合团队选择，失败整轮回滚 |
| nrd3 | `nrd3.py` + `nrd_dict.py` | **dictionary 自我进化**：带类型的程序语法（naive / 季节 / 漂移 / SES / 阻尼趋势 / theta / 线性回归 / 季节轮廓，加混合、路由、裁剪），只看历史的回测作为 fitness，按"频率 × 季节性"分格做 MAP-Elites | 逐条修正的校验器（特征权重），用逐条修正收益做 ES 进化 | 把回测最好的 dictionary 方法混入 Toto（Toto 权重 ≥ 0.5） | 在训练集分层 fold 上做团队选择 |
| **nrd4**（主结果） | `nrd4.py` | 只看历史的判断：幅度校准器（进化）+ 按格子的 Toto 可信度画像 | 同上的逐条校验器，加入 Numerical 的特征（幅度 / 历史波动、可信度） | 2 个参数：强度、可信度门槛；**不做混合** | 同上 |
| nrd5 | `nrd5.py`、`nrd5_extract.py` | 幅度 = k[强度档] × 历史波动 σ | **进化抽取程序**：文档筛选器 + GPT 指令（GPT-6-sol 作为变异算子） | 置信度阈值 + 可信度门槛 | 程序的 fitness 是训练 CV |
| nrd6 | `nrd6.py` | 历史偏差特征 | 结构化的逐步特征 | ridge 残差修正器 + **conformal** 不伤害门槛 | 进化特征组合和正则强度 |
| nrd7 | `nrd7.py` | 同 nrd5 | 3 个模型分别抽取 + 证据核对 + 多模型共识 | 同 nrd5 | — |
| nrd8 | `nrd8.py` | 同 nrd4 | 加上可进化的窗口 / 方向变换 | 同 nrd4 | 同 nrd4 |
| nrd9 cards | `nrd9_extract.py` | — | 精确时间的 GPT 重新抽取（每个任务单独调用，读全部文档） | — | 放进 nrd4 运行 |
| nrd10 | `nrd10.py` | 同 nrd4 | 新旧 cards 合并 + 两个抽取器是否一致作为特征 | 同 nrd4 | 同 nrd4 |

| nrd12 | `nrd12.py` | 同 nrd11 | 同 nrd11 | 同 nrd11 | **GEPA 式按任务的 Pareto 选择 + 3 个岛屿（迁移）+ 多数投票集成** |

诊断：
- **"只接受有用修正"的天花板**（旧 cards）：训练集 +11.1%，dev +1.8%。训练集 75 条修正里只有 29 条有用。

  - 窗口 / 时间不对：26 条；

  - 幅度太大：7 条；

## 4. 主方法 nrd4 最终进化出的具体内容（在全部训练集上的最终团队）

**Numerical**
- 幅度校准器：经过进化，但最终几乎等于初始设定 `{窗口: 全部, 去季节性: 否, 参照: 中位数, 统计量: q90, 倍数 ≈ 1.0–1.03}`。
- Toto 可信度画像，即每个格子 Toto 回测误差的中位数（固定统计量）：day|flat 1.81，day|seas 0.16，hour|seas 0.87，hour|flat 0.51，minute|seas 0.22，minute|flat 0.58，second|flat 1.21。

**Retrieval**（逐条修正校验器；seed 1/2/3 的权重）：

| 特征 | seed 1 | seed 2 | seed 3 |
|---|---|---|---|
| absmag（修正幅度） | +3.25 | +1.49 | +3.87 |
| conf（置信度） | −0.07 | +0.58 | −1.18 |
| wfrac（窗口占比） | +0.63 | +0.66 | +1.07 |
| docbase（说明类文档比例） | **−2.77** | **−2.38** | **−3.72** |
| ratio（幅度 / 历史波动） | ≈0 | ≈0 | ≈0 |
| trust（Toto 可信度） | +1.02 | +0.34 | +0.77 |
| bias（截距） | −2.75 | −1.55 | −1.75 |

学到的规则：接受有事件类文档支撑的大修正，拒绝来自说明类 / 方法论文档的修正；Toto 越不可靠的地方，越相信文档。

**Decision**：强度 1.0，可信度门槛 0 ~ 0.07。

**tl2 进化后的 Retrieval 抽取指令**（第 4 代，全文在 `tl2_best.json`）。GPT 根据训练集反馈学到的主要规则：
- 优先采用直接针对目标的陈述和明确的假设条件（"假设""suppose"），而不是日志或报告；
- 其他实体的事件只有在明确关联到目标时才采用；
- 区分"测量错误"和"真实而持久的变化"，并保留"本周不再发生""将来都不会发生"这类表述的准确范围；
- 只有在明确说了会重复、或数据里确实出现多个周期时，才标为周期性模式；
- 不插值猜测边界，引用完整证据原文。

## 5. 结论

1. **按严格协议，主结果是 nrd4。**
   - 训练 CV +6.4%，高于手工方法的 +4.6%；dev 3/3 通过。
   - test（探索性）：sMAE +3.5%，sRMSE +6.2%，约 30 个变好、1 到 2 个变差。在 test 上仍低于手工方法。
2. **Numerical 的贡献。**
   - 把 dictionary 方法混入 Toto 是变差任务的主要来源：关掉混合后，训练 CV 从 +2.0% 升到 +5.5%，变差任务从 45 个降到 19 个。
   - 作为判断特征时，Numerical 的信号有用：从 +2.7% 提到 +6.4%。几乎全部来自格子级的可信度画像；进化出的校准器基本没有变化。
   - 两阶段版本（nrd11，先进化 dictionary 再联合进化）确实用上了 dictionary 特征，但效果和 nrd4 持平。
3. **在 80 个训练任务的规模下，搜索越强越容易过拟合。** GEPA 式的 Pareto 选择 + 岛屿把训练 CV 提到 +8.1%（9/9 个 fold 为正），但没通过 dev，test 上也不如 nrd4。
4. **瓶颈在文档抽取，而不在筛选。** 最大的新杠杆是**历史修复**：Dr-CiK 的文档经常说明"过去某段数据是异常的、以后不会再发生"。用 gt_evidence 进化后的 Retrieval 能更好地抽出这类信息（F1 从 0.04 升到 0.48）。
   - 只做历史修复，test sMAE 就达到了所有方法里最高的 +11.7%（探索性）。
   - **但目前还不稳**：dev −3.8%，test 上 10 个变好、13 个变差。失败的原因是把自然的日周期当成了异常，以及补值方法不够好。
5. **下一步：**
   - 用只看历史的回测来验证每一次修复（Decision）；
   - 进化补值方法（Numerical）；
   - 在抽取指令里加上"自然周期不算异常"的约束；
   - 然后把历史修复和 nrd4 的未来修正叠加；
   - 之后只用训练 CV 和 dev 判断；如果官方渠道可用，用 Dr-CiK 的隐藏标签子集作为干净的最终测试。
