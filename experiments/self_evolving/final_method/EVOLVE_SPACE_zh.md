# Evolve space 与流程设计

本文说明主方法里每个可进化部分的设计：
- 进化的对象是什么；
- 搜索空间有多大；
- 怎么变异，怎么打分，怎么选择；
- 用了哪些数据。

结果数字见 `README.md`，逐代记录见 `EVOLUTION_LOG.md`，方法概述见 `METHOD_zh.md`。

数据划分：Dr-CiK 训练集 80 个任务，dev 20 个，test 99 个。**所有进化只用训练集**；dev 在全部进化结束后只打开一次，作为把关；test 之前已经打开过多次，数字只作参考。误差指标是 sMAE + sRMSE（单任务上限 5），下文统称"联合误差"。

## 1. 整体流程

进化按下面的顺序进行，后一步用前一步的产物：

```
①  Numerical 第一部分：进化"组合程序"  ──→ 基础预测
②  Retrieval：进化抽取指令               ──→ 过去的异常时间段
③  Numerical 第二部分 + Decision：从候选里选补值方法和修复门槛 ──→ 是否用修复后的历史
④  三角色联合进化（nrd4）                ──→ 对未来的逐条修正
```

推理时对一个任务：
1. 用 ② 的指令抽出"不会再发生"的过去异常，用 ③ 选出的补值方法修复历史，Toto 在修复后的历史上重新预测；
2. 只看历史做回测，修复后误差下降超过门槛才采用；
3. 把采用的 Toto 预测代入 ① 的组合程序，得到基础预测；
4. ④ 的团队决定每条文档修正是接受、减半还是拒绝，再作用到基础预测上。

| 步骤 | 进化对象 | 打分依据 | 脚本 | 产物 |
|---|---|---|---|---|
| ① | 组合程序（方法、权重、差分项、收缩、裁剪） | 训练集联合误差 | `scripts/num_part1.py` | `artifacts/numerical_part1_dictionary.json` |
| ② | 自然语言抽取指令 | 训练集标准证据 F1 | `scripts/tl2_evolve.py` | `artifacts/tl2_evolved_extraction_instructions.json` |
| ③ | 补值方法 × 修复门槛 | 训练集上整条流水线的联合误差 | `scripts/select_fill_gate.py` | `artifacts/fill_and_gate_choice.json` |
| ④ | 幅度校准器、逐条校验器、强度和门槛 | 训练集分层 fold 上的团队收益 | `scripts/nrd4.py` | `artifacts/nrd4_final_teams.json` |

## 2. ① Numerical 第一部分：组合程序

**基因型（一个程序）**

```
f = Σ w_i · M_i            （1 到 4 项，权重归一化为 1）
  + c · (M_a − M_b)        （可选的差分修正项）
f ← (1 − s)·f + s·y_last   （可选：向最后观测值收缩，s ∈ [0, 0.6]）
f ← clip(f, 历史范围 ± r·幅度)  （可选：r ∈ {0, 0.1, 0.25, 0.5}）
```

其中 M_i 是 dictionary 里的方法预测。当前主方法的 dictionary 包括：
- 原有 31 个方法；
- 93 个统计方法（其中 48 个能在 Dr-CiK 上出预测）；
- 覆盖至少 90% 训练任务的 37 个方法进入搜索，缺失时用 Toto 代替。

**第 0 代**：每个单一方法各自作为一个程序，Toto 只是其中之一。

**变异算子**（每次随机选一种）：
- 换方法：把某一项换成另一个方法；
- 改权重：某项权重乘以 2^N(0, 0.5)（出现概率是其他算子的两倍）；
- 加项或删项；
- 加入、删除或重抽差分项 (M_a, M_b, c)，其中 c ~ N(0, 0.2)；
- 调整收缩强度：s ± N(0, 0.1)；
- 开关裁剪，或更换裁剪范围。

**fitness**：`训练集平均收益 + 3 × 平均负收益`。收益 = Toto 的联合误差 − 程序的联合误差。把任务变差的部分多罚 3 倍，是"不伤害"约束。

**选择**：每代 12 个父代，产生 24 个子代，父代和子代合并排序，共 30 代。为保持多样性，每个"主导方法"（权重最大的那一项）至少保留一个最优程序。最后留下 8 个主导方法不同的精英程序，组成候选 dictionary，第 1 名作为基础预测。

**无偏性检查**（对照实验，见 README）：把 fitness 改成不以 Toto 为参照（以所有单一方法误差的中位数为参照），进化仍然选出以 Toto 为主的程序。

## 3. ② Retrieval：抽取指令

**基因型**：一段自然语言指令。GPT（gpt-6-luna）按这段指令读每个任务的全部文档，输出结构化时间线。

**输出格式（人工固定）**：每条区间包括：
- 类型：测量错误、一次性干扰、周期性异常、状态、未来事件；
- 起止时间；
- 重复方式：不重复、每天、每周、每 n 天，以及每天的起止时刻；
- 以后是否还会发生；
- 方向；
- 原文引用。

**第 0 代**：人工写的初始指令。

**变异算子**：由 GPT（gpt-6-sol）改写指令。输入是当前指令和最多 12 条错误反馈，每条反馈说明"漏掉了哪条标注证据"或"引用了哪段不是证据的话"。要求保持输出格式不变，只改规则。

**fitness**：在固定的 30 个训练任务上，抽取结果和标准证据标注（gt_evidence）之间的 F1。这是比最终误差更密的信号，而且只用训练集的标注。

**选择**：每代生成 2 个子代，最好的子代 F1 必须高于当前指令才接受，否则回滚，共 4 代。

**进化出的规则**举例：
- 其他实体的事件只有明确关联到目标序列才采用；
- 区分测量错误和真实而持久的变化；
- 保留"本周不再发生"和"以后都不会发生"之间的区别；
- 不插值猜测时间边界。

## 4. ③ Numerical 第二部分 + Decision：补值方法和修复门槛

**搜索空间**：4 种补值方法 × 6 种门槛，共 24 种配置。
- 补值方法：同相位中位数、线性插值、季节 naive、截断；
- 门槛：0、5%、10%、20%、30%，以及"不修复"。

**修复与校验**：
- 修复：②抽出的"以后不会再发生"的异常段，用补值方法填上，Toto 在修复后的历史上重新预测。
- 校验：只用历史，把最后一段留出来，分别用原始历史和修复后的历史做回测。修复后误差下降超过门槛才采用修复。

**fitness**：训练集上整条流水线（① + 修复 + ④）的 `平均收益 + 3 × 平均负收益`。

**选择**：搜索空间小，直接全部评估取最好的。嵌套交叉验证（在 2 个 fold 上选、在第 3 个 fold 上评估）三折 held-out 都是正收益。

**结果**：同相位中位数，门槛 30%。

## 5. ④ 三角色联合进化（nrd4）

文档给出的未来修正（起止步和倍数 m）来自一次性抽好的 cards。团队决定每条修正怎么用。

**Numerical（数值判断）**
- 幅度校准器 σ(历史)：给出"这条序列正常波动有多大"。
  - 基因：窗口长度 {全部, 1, 2, 3, 5, 8}×H、是否去季节、参照值（中位数、均值、最后值）、统计量（q90、q75、标准差、MAD）、倍数。
  - 变异：每次改其中一项。
  - fitness：只用历史。在历史内部滚动留出下一段，看 σ 能否预测实际偏离的大小（对数比误差）。
- Toto 信任度：按序列形态分格（频率 × 是否有季节性），每格取 Toto 在历史回测上的误差中位数。这一项是统计出来的，不进化。

**Retrieval（逐条校验器）**
- 基因：7 个特征的逻辑回归权重。特征是：
  - 修正幅度 |m − 1|；
  - 文档置信度；
  - 修正窗口占预测长度的比例；
  - 文档里"说明、方法论"类词汇的比例；
  - |m − 1| / σ（修正相对于正常波动有多大，来自 Numerical）；
  - Toto 信任度（来自 Numerical）；
  - 偏置。
- 输出：概率 > 0.6 接受，0.35 到 0.6 减半，否则拒绝。
- 进化方式：进化策略，种群 16、精英 4、15 代，变异步长逐代减小。
- fitness：逐条修正的收益之和，变差的部分按 1.5 倍惩罚。

**Decision（决策）**
- 基因：修正强度 ∈ [0, 1]，信任门槛 ∈ [0, 2]。在 Toto 信任度高的格子里，完全不动 Toto。
- 变异：加高斯噪声。

**联合进化**
- 第 0 代：校验器拒绝所有修正，也就是输出和 Toto 完全相同。
- 每代：三个角色各自产生候选，随机组成 32 个团队，并保证每个团队至少有一个角色是新的。
- 团队 fitness：在训练集 3 个分层 fold 上，`各 fold 稳健收益的平均 − 0.25 × fold 间标准差`。其中稳健收益 = 平均收益 + 0.5 × 平均负收益。
- 接受规则：最好的团队必须超过当前团队才接受，否则**整轮回滚**。
- 预算：15 代，3 个 seed。

## 5b. 统一端到端打分与 agent 协同进化（2026-09-28 新增）

**第 1 步：合作式协同进化，只用一个端到端分数**
- **进化对象**：三个角色的全部可调部分：
  - Numerical：组合程序、幅度校准器；
  - Retrieval：逐条校验器，外加每 2 或 3 轮一次由 GPT 改写抽取指令；
  - Decision：补值方法、门槛、强度、信任门槛。
- **流程**：每轮每个角色产生 40 个只改自己的候选，其他角色固定为当前最好的版本。
- **fitness**：整条流水线在训练集 fold 上 `稳健收益的平均 − 0.25 × 标准差`，其中稳健收益 = 平均收益 + 0.5 × 平均负收益。和第 ④ 步相同。
- **接受规则**：两种都试过：只看平均值变好；或者平均值变好且每个 fold 都不变差。
- **结果**：嵌套交叉验证里，留出 fold 三折都变差，说明过拟合，不采用。

**第 2 步：agent 提议者（CORAL / Meta-Harness 式）**
- **提议者**：Codex agent。可以读可见任务的完整数据（历史、真实值、各方法预测、文档、修正、主方法的逐任务结果），也可以自己写分析脚本，然后提交完整配置。
- **评估器隔离**：
  - agent 不能自己跑评估，只能通过队列提交；
  - 训练集 fold 0、1 可见，返回分数和逐任务收益；
  - fold 2 隐藏，只返回"通过或不通过"；
  - 隐藏 fold 的逐任务结果只保存在 agent 读不到的位置。
- **接受规则**：可见分数提高，并且隐藏 fold 的稳健收益不低于当前最好的配置。
- **预算**：每个 agent 20 次提交，其中最多 2 次可以改抽取指令，因为每次要重新抽取，大约 30 分钟。
- **共享记忆**：`attempts/`（所有提交和可见结果）、`notes/`（观察、假设、"什么从来没用过"）、`skills/`（可复用的分析脚本）。
- **heartbeat 提醒**：每轮提醒记笔记；每隔一轮提醒整理笔记、沉淀成脚本；上一轮没有被接受的改动时，提醒换方向。
- **对照**：3 个 agent 共享记忆，对比 3 个 agent 各自独立。
- **结果**：隐藏 fold 拦下了 17 次只在可见数据上变好的提交。最终采用独立 agent 找到的"基础预测里加 10% TimesFM"。3 个 seed 在 test 上每一个都变好，于是成为新的主方法。

## 6. 防过拟合的设计

- **数据隔离**：所有进化和选择只用训练集。dev 只在最后打开一次。标准证据标注只用训练集的。
- **不伤害约束**：①、③、④ 的 fitness 都对变差的任务额外惩罚。
- **分层 fold**：每个任务组都分散到各个 fold，和训练集到 test 的分布一致。④ 的团队 fitness 还惩罚 fold 间的方差。
- **回滚**：② 和 ④ 的子代如果不如当前，就整体回滚。
- **嵌套交叉验证**：①、③ 都报告了在未参与选择的 fold 上的结果。
- 已知的污染：① 的惩罚系数 3 是在看过惩罚系数 0.5 那一版的 dev 和 test 之后定的。

## 7. 尝试过但没有进入主方法的 evolve space

| 设计 | 做法 | 结果 |
|---|---|---|
| 历史处理 dictionary（dict2） | 进化"异常来源 × 补值 × 平滑 × 截断"的历史处理程序，只用历史回测打分 | 通过 dev，但 test 上没有收益 |
| 带统计混合的 dictionary（dict3） | 在 dict2 上再加统计方法混合、偏差校正、幅度缩放 | 没有通过 dev |
| 合并抽取器（tl5） | 同一个抽取器同时产出过去的异常和未来修正，用标准证据 F1 进化 | 3 代 6 个子代都没超过第 0 代（F1 0.471） |
| 补全 5 个基础模型和 5 个组合方法 | dictionary 扩到 43 个方法，并试了不以 Toto 为参照的 fitness | 进化仍选 Toto + ARIMA + 收缩；整条流水线 dev 略差 |
| 抽取指令用全部 80 个训练任务再进化 | 以 30 任务版本为起点，每代 4 个子代 | 证据 F1 0.477 → 0.553，但预测变差（dev 0.3477 / 0.5180） |
| 统一端到端打分 + 随机搜索 | 见 5b 第 1 步 | 留出 fold 三折都变差（过拟合） |
